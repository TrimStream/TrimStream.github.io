Personal portfolio website built with Next.js and TypeScript.

Live at [trimstream.github.io](https://trimstream.github.io)

## Tech Stack

Next.js, TypeScript, React, CSS

## Running Locally

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
